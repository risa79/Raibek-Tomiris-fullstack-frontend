# SkillSwap — обмен навыками между студентами

Учебный frontend MVP: студенты предлагают свои навыки в обмен на другие (например, английский в обмен на помощь с Python).

## Страницы
- `index.html` — главная, описание идеи и примеры предложений.
- `offers.html` — каталог, поиск, фильтр и модальное окно запроса.
- `profile.html` — создание и удаление предложений, просмотр сохранённых запросов.

## Технологии
HTML5, CSS3 (переменные, Flexbox, Grid, медиазапросы), JavaScript без фреймворков, `localStorage`.

## Структура
```
index.html
 offers.html
 profile.html
 css/style.css
 js/app.js
 img/ (для будущих изображений)
 README.md
```

## Функции
- Адаптивное меню для мобильных устройств.
- Поиск по имени, навыкам и описанию; фильтр по категории.
- Создание предложения с проверкой заполнения полей.
- Удаление своих предложений.
- Модальное окно запроса на обмен с проверкой сообщения.
- Сохранение предложений и запросов в localStorage.

**Ограничения MVP:** данные хранятся только в текущем браузере. Нет регистрации, сервера, реального обмена сообщениями или синхронизации между студентами. Демо-предложения являются вымышленными.

## Запуск
Откройте `index.html` в браузере или используйте VS Code Live Server.

Если ведёте разработку поэтапно, делайте коммиты после каждого этапа:

4. `style: make layout responsive with media queries`

## Публикация на GitHub Pages
1. Создайте публичный репозиторий `surname-name-fullstack-frontend`.
2. Загрузите файлы и выполните коммиты.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
5. Дождитесь публикации и добавьте ссылку на сайт и скриншоты в README.

## Для защиты
- **HTML**: семантические `header`, `nav`, `main`, `section`, `footer`, `article`, `form`.
- **CSS**: переменные `:root`, общие классы `.btn`, `.card`, Grid и медиазапросы.
- **JavaScript**: `addEventListener` реагирует на действия; `filter` ищет; `createElement` безопасно создаёт карточки; `localStorage` сохраняет JSON.
- **Валидация**: проверяем длину полей и выводим ошибку, прежде чем сохранить данные.
- **Диалог**: нативный `<dialog>` открывается через `showModal()`.
